# 钓遍中国 FishingChina

PICO Project Swan 上的全沉浸钓鱼游戏：玩家坐在杭州西湖、千岛湖、桂林漓江、查干湖冰面上钓鱼，每处有自己的鱼和任务。设计方案见 `../../docs/选题方案_钓遍中国.md`。

> 2026-11-02 v0.1（versionCode 1）：
> - 四处名湖（西湖、千岛湖、漓江、查干湖冰钓），银奖杯解锁西湖月夜钓锦鲤，金奖杯解锁查干湖头鱼。十种鱼，各有爱吃的饵、喜欢的远近和石头边。
> - 操作：捏一下开始蓄力、再捏一下抛竿；浮漂轻点（试探）时别提竿，沉下去才提；搏鱼时鱼在冲就别收线，不然断线；拉近了用抄网。
> - 每处三个任务，星级等于完成的任务数。铜奖杯（铜鱼钩）、银奖杯（解锁西湖月夜）、金奖杯（金色鳙鱼标本、隐藏鱼王查干湖头鱼和珍藏画）。
> - 两个窗口：钓场地图（选钓场、奖杯）和鱼类图鉴。
> - 自动测试 3 个（每处都能拿到三星、鱼冲时收线会断线、浮漂试探时提竿会惊跑鱼）；调试钩子 AutoPilot（logcat 标签 FishTest），`walk` 自动钓完全部钓点。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`：`FishingChina-debug.apk`（带调试钩子）和 `FishingChina-release.apk`（正式签名）。商店素材在 `商店素材/`，素材来源和授权见 `docs/素材来源.md`，背景音乐的备选试听在 `docs/音乐候选/`。
